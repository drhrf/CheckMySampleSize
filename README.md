The goal of CheckMySampleSize is to help researchers translate a planned sample size into realistic, defensible analysis choices—by offering plain-language feasibility guidance that adapts to the primary analysis goal, the number of groups, and basic inferential targets (α and power), while discouraging over-parameterized, underpowered, or multiplicity-heavy designs.
